Hackathon Judge Presentation Cheat Sheet

        3-Minute Demo Playbook
      


      

        

          Judge: "What is genuinely unique here?"
          

            "Most systems either blindly trust bad input data or halt entirely. We pair conservative data repair and proof-carrying quarantine with a dependency-aware power recovery engine under limited backup power. We never hallucinate or guess bad data."
          

        

        

          Judge: "Why not use AI to fix the bad rows?"
          

            "If a field contains 'ninety', an AI or regex cannot prove whether it meant 90, 19, or 90.0. In life-critical infrastructure, guessing can cause catastrophic failure. AutoShield quarantines untrusted records and exports proof evidence."
          

        

        

          Judge: "Does it control actual power hardware?"
          

            "No. It is an in-memory software prototype with synthetic data. It is not connected to SCADA or physical grid hardware, and recovery uses a deterministic greedy heuristic rather than physics modeling."
          

        

        

          Judge: "What would you build next?"
          

            "We would integrate mixed-integer programming (MIP) for optimal power scheduling, live SCADA sensor streaming, role-based access control, and cryptographic hardware signing for the audit ledger."
